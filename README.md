# Alicia's Jordan Journey

A static travel-planning guide for a Jordan trip.

## Project Structure

```text
.
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── app.js
│   └── images/
│       ├── attractions/
│       ├── culture/
│       ├── food/
│       ├── hero/
│       ├── media/
│       │   ├── books/
│       │   └── movies/
│       └── places/
```

## Notes

- `index.html` contains the page content and semantic structure.
- `assets/css/styles.css` contains all styling.
- `assets/js/app.js` contains the email-choice behavior.
- Images are grouped by the section where they are used.
